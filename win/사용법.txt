flowapp — 수급분석 스캐너 (윈도우판)

■ 시작하기
  1. 압축을 원하는 곳에 풉니다 (예: 바탕화면, D:\flowapp).
     ※ C:\Program Files 아래는 피하세요(쓰기 권한 문제).
  2. 「flowapp 실행.bat」을 더블클릭합니다.
     - 처음 한 번은 시세·수급 데이터(약 1.2GB)를 받아 설치합니다. 인터넷 속도에 따라 몇 분 걸립니다.
     - 이어서 지표를 계산합니다(1~5분). 끝나면 브라우저가 자동으로 열립니다.
  3. 검정 창은 프로그램 본체입니다. 이 창을 닫으면 프로그램이 꺼집니다.
     다시 쓰려면 「flowapp 실행.bat」을 또 누르면 됩니다.

  "Windows의 PC 보호" 파란 창이 뜨면 → 「추가 정보」 → 「실행」.

■ 내 API 키 넣기 (상단 메뉴 「설정」)
  - 키움 REST API 앱키·시크릿키: 매일 새 수급·5분봉을 받는 데 필요합니다.
      https://openapi.kiwoom.com 에서 REST API 신청 → 이 PC의 공인 IP를 허용 IP로 등록.
      키가 없어도 같이 받은 데이터로 검색·차트는 됩니다(시세만 갱신).
  - DART 인증키(선택, 무료): 종목 화면의 공시·재무.  https://opendart.fss.or.kr
  - Anthropic API 키(선택, 유료): AI 견해.
  키는 이 PC에만 저장됩니다:  %LOCALAPPDATA%\flowapp\config

■ 매일 쓰기
  - 화면 위 「최신 데이터 받기」: 오늘까지 시세·수급·분봉을 받습니다(장 마감 후 18시 이후 권장).

■ 프로그램 업데이트
  - 「설정」 → 「업데이트 확인」 → 「업데이트 설치」. 받고 나서 자동으로 다시 켜집니다.
  - 데이터와 키는 그대로 남습니다.

■ 데이터·설정 위치
  %LOCALAPPDATA%\flowapp   (탐색기 주소창에 그대로 붙여 넣으면 열립니다)
    market\  데이터와 계산 캐시     config\  키     logs\  실행 기록
  프로그램 폴더를 지우고 새로 받아도 이 폴더는 그대로 씁니다.
